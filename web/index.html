Overnight sweep

Build date ranges + experiment rows. Each row is a param set (short names). Comma-separate values in a cell to expand (e.g. 1.8,2.0,2.2). Range + spike share one load/replay each run. Default pairing is Together: each range variant runs with one spike variant (shorter list cycles) — not a full product. Optional full grid = every range × every spike. Report: top 3 T by clean % per engine, by date range.

Speed: ticks load once per date range, then all param variants replay on that pack. Workers > 1 run date groups (or split variants) in parallel processes — uses more CPU cores. Stop still finishes the current worker jobs.

Together (default): 3 range mults + spike win 60,90 → 3 runs per date (not 5, not 6). Each run fires both engines; the shorter list cycles: (1.8+60), (2.0+90), (2.2+60). Count = dates × max(range variants, spike variants) — so editing the smaller side may not change the total until it exceeds the other (live counter shows both: range N · spike M). Full grid: every range × every spike (3×2=6).

Empty table = no runs (nothing is invented). Fill at least one cell, or click + Defaults only for one Reaktor-defaults experiment. Blank placeholder rows do not count.

Spike experiments

Same: empty = no runs. Use + Defaults only if you want baseline defaults.

Spike Neo experiments

Coil → expand → structure hold (15m). Independent of classic Spike. Empty = no neo runs unless another engine has rows (then neo uses defaults as partner).

Impulse retrace experiments

After a directed blast, alert at pullback fractions (default 50% then 75%). Bias = blast direction. Must hit a level within max_age sec of the blast extreme (default 120); no fire past max_depth (default 0.85). fracs = list in one experiment (e.g. 0.5,0.75), not cartesian expand. Optional coil gate: quiet (true/false), quiet_n, quiet_sw.

Range wick experiments

Older wick-latched range (source candle_wick). Uses forming H/L for directed move — A/B vs live range. Same short names as range live (mult, min_dir, hold, struct, …).

Moldova H1 clock

  1. Direction from first of 6am → 5am → 4am H1 with range ≥ $15 and a real body (Europe/Chisinau).
  2. Enter at 07:00 local, same direction as that bar.
  3. Stop from the 5am high/low, at least 500 pts.
  4. At 09:00 close if not red; if red, wait for breakeven or SL or 12:00 flatten.

Parameters

Dates are Moldova calendar days. Only 3am–12pm local hours are loaded (not full days). Fill is mid. One trade per weekday. Weekends skipped.

Fade a 1–3s spike

  1. If price moves ≥ 2000 pts in ≤ 3 seconds, enter the other way (optionally after 1–2s lag).
  2. Take profit and hard stop are a % of that spike (100% = fade the whole move). Set % to 0 to use fixed pts instead.
  3. After +1000 pts, trail 1000 behind the best price (at worst breakeven).
  4. Flatten after 2 minutes if still open. Skip the first 10 min after weekend reopen (Sun 22:00 UTC).

Full-day ticks (all hours), not Session’s 3am–12pm slice. Mid fill — live will be worse. A year is scanned one month at a time so RAM and the progress bar stay alive.
