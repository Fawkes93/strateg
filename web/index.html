Overnight sweep

Build date ranges + experiment rows. Each row is a param set (short names). Comma-separate values in a cell to expand (e.g. 1.8,2.0,2.2). Range + spike share one load/replay each run. Default pairing is Together: each range variant runs with one spike variant (shorter list cycles) — not a full product. Optional full grid = every range × every spike. Report: top 3 T by clean % per engine, by date range. Avg/sum pts use a hard SL at opposite% × T — dirty hits (T after the stop) count as losses. Seasonal month + 2-week trend apply only to Spike Neo and Impulse retrace. If they disagree, both are tagged and the run keeps both sides; otherwise against-sides are filtered.

Speed: ticks load once per date range, then all param variants replay on that pack. Workers > 1 run *different date ranges* in parallel (one month stays one process — no variant split). Stop kills workers.

Together (default): 3 range mults + spike win 60,90 → 3 runs per date (not 5, not 6). Each run fires both engines; the shorter list cycles: (1.8+60), (2.0+90), (2.2+60). Count = dates × max(range variants, spike variants) — so editing the smaller side may not change the total until it exceeds the other (live counter shows both: range N · spike M). Full grid: every range × every spike (3×2=6).

Coil → expand → structure hold (15m). Independent of classic Spike. Empty = no neo runs unless another engine has rows (then neo uses defaults as partner).

Impulse retrace experiments

After a directed blast, alert at pullback fractions (default 50% then 75%). Bias = blast direction. Must hit a level within max_age sec of the blast extreme (default 120); no fire past max_depth (default 0.85). fracs = list in one experiment (e.g. 0.5,0.75), not cartesian expand. Optional coil gate: quiet (true/false), quiet_n, quiet_sw.

Range wick experiments

Older wick-latched range (source candle_wick). Uses forming H/L for directed move — A/B vs live range. Same short names as range live (mult, min_dir, hold, struct, …).

Moldova H1 clock

  1. Direction from first of 6am → 5am → 4am H1 with range ≥ $15 and a real body (Europe/Chisinau).
  2. Enter at 07:00 local, same direction as that bar.
  3. Stop from the 5am high/low, at least 500 pts.
  4. At 09:00 close if not red; if red, wait for breakeven or SL or 12:00 flatten.

Parameters

Dates are Moldova calendar days. Only 3am–12pm local hours are loaded (not full days). Fill is mid. One trade per weekday. Weekends skipped.

Fade a 1–3s spike

  1. If price moves ≥ 2000 pts in ≤ 3 seconds, enter the other way (optionally after 1–2s lag).
  2. Take profit and hard stop are a % of that spike (100% = fade the whole move). Set % to 0 to use fixed pts instead.
  3. After +1000 pts, trail 1000 behind the best price (at worst breakeven).
  4. Flatten after 2 minutes if still open. Skip the first 10 min after weekend reopen (Sun 22:00 UTC).

Full-day ticks (all hours), not Session’s 3am–12pm slice. Mid fill — live will be worse. A year is scanned one month at a time so RAM and the progress bar stay alive.

Fade a stalled burst

  1. Detect a 100–300 pt one-way burst in a few seconds (little pullback).
  2. If price makes no new extreme for the pause (0.5–2s), enter the opposite side (ask long / bid short).
  3. Take 25–50% of the burst at 1:1 RR. Trail arms at ½R (stop to BE). Flatten after max hold.

1 pt = $0.01 on XAU. Default: all hours, pause 1s, TP = 50% of burst, SL = TP, trail frac 0.5. Huge verticals (≥ max burst) stay with Spike fade. Quiet = Asia 22–07 UTC plus 20:00–23:00 Chisinau.

Join a mini wave

  1. If mid runs min–max pts in 1–3 seconds with little pullback, enter with that burst.
  2. Fill at ask (long) / bid (short). Scalp a few pts of continuation.
  3. Optional: move SL to break even as soon as price is in favor. Else hard SL / max hold.

1 pt = $0.01 on XAU. Default: 50–100 pts in 2s, TP 30 / SL 40, max spread 15. TP/SL are measured from bid (long) / ask (short) so the spread does not instantly stop you out. If spread ≥ TP or SL the trade is skipped — otherwise you get fake 5–10% win rates.

Trend cool-off (15m)

  1. Lock a directional run of at least 5 × 15m candles (whichever way price just went).
  2. Reverse if price pulls back > 30% of that run within 2–3 pause candles — enter opposite, on the tick that tags the level.
  3. Join if the pullback stays < 30% over the last 2–4 bars and the forming candle reclaims the run’s higher high / lower low — enter with the trend immediately.

Mid fill. One trade at a time. Pause bar 1 is tracking only (a reclaim there is the run continuing, not a join). Months scan in parallel like Spike fade.

Parameters

Fill

Natural = join with the run, reverse against a deep pullback. Opposite = flip every fill to test the other side.
